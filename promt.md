# Промт для создания игры «Block Blast» в виде Telegram Mini App

Скопируй этот промт целиком и отдай его AI-ассистенту (Claude, ChatGPT и т.д.) или разработчику — он описывает задачу полностью: от механики игры до технической интеграции с Telegram.

---

## ЗАДАЧА

Разработай веб-игру в жанре «Block Blast» (головоломка на сетке с блоками, аналог Tetris + Sudoku) и упакуй её как **Telegram Mini App**, чтобы она открывалась прямо внутри Telegram через бота, без установки отдельного приложения.

---

## 1. Игровая механика (Block Blast)

- Игровое поле — сетка **8×8 клеток**.
- Внизу экрана показываются **3 случайные фигуры** (составленные из 1–5 квадратов, формы как в Tetris/пентамино).
- Игрок перетаскивает фигуру на поле (drag-and-drop / тап-и-перенос, с поддержкой touch-событий).
- Фигуру можно поставить только если все её клетки помещаются на свободные клетки сетки.
- Когда полностью заполняется **строка или столбец** — она очищается (взрывается), клетки в ней зануляются с анимацией.
- Очистка нескольких линий одновременно даёт бонусные очки (комбо).
- Когда все 3 фигуры размещены — выдаются 3 новые случайные фигуры.
- Игра заканчивается, когда ни одну из трёх текущих фигур невозможно разместить на поле (game over).
- Ведётся счёт очков: +очки за размещение блоков, +больше очков за очистку линий, множитель за комбо (несколько линий подряд без паузы).
- Сохраняется **лучший результат (high score)** локально и/или на сервере.

### Дополнительные механики (опционально, если хватит объёма):
- Специальные блоки (бомба, блок-джокер, радужный блок).
- Ежедневные челленджи / уровни с целями.
- Подсказка (highlight) — куда можно поставить фигуру.
- Отмена хода (ограниченное число раз, за просмотр рекламы или внутриигровую валюту).

## 2. Требования к UI/UX

- Минималистичный, яркий, «мобильный» дизайн (крупные тач-зоны, отступы, без мелких элементов).
- Адаптивная вёрстка под экран Telegram Mini App (портретная ориентация, разные размеры экранов телефонов).
- Анимации: появление фигур, взрыв линий, тряска при неудачном ходе, партиклы при комбо.
- Звуковые эффекты (клик, взрыв линии, game over) — с возможностью отключить звук.
- Экран Game Over с результатом, кнопкой «Играть снова» и кнопкой «Поделиться результатом».
- Поддержка тёмной/светлой темы **синхронно с темой Telegram** (см. раздел про Telegram SDK ниже).

## 3. Технический стек

- **Frontend:** HTML5 + CSS + JavaScript (Canvas API или PixiIO/PixiJS для рендеринга сетки и анимаций), либо React, если нужен более сложный UI.
- **Telegram интеграция:** [Telegram Web Apps SDK (telegram-web-app.js)](https://core.telegram.org/bots/webapps) — обязательно подключить `<script src="https://telegram.org/js/telegram-web-app.js"></script>`.
- Использовать методы Telegram SDK:
  - `Telegram.WebApp.ready()` и `Telegram.WebApp.expand()` — разворачивание на весь экран;
  - `Telegram.WebApp.themeParams` — подхват цветовой темы пользователя;
  - `Telegram.WebApp.MainButton` — например, кнопка «Играть снова» или «Поделиться»;
  - `Telegram.WebApp.HapticFeedback` — вибро-отклик при взрыве линий и ошибках;
  - `Telegram.WebApp.sendData()` — отправка результата обратно боту (если нужно сохранять статистику через бота);
  - `Telegram.WebApp.CloudStorage` — для сохранения high score в облаке Telegram без своего бэкенда.
- **Backend (опционально):** Node.js + Express (или Python + aiogram/python-telegram-bot) для самого Telegram-бота, который открывает Mini App через кнопку меню или inline-кнопку.
- **База данных (опционально):** для таблицы лидеров — SQLite/PostgreSQL/Firebase.

## 4. Интеграция с Telegram-ботом

1. Создать бота через **@BotFather**, получить токен.
2. В @BotFather включить **Menu Button** и указать URL веб-приложения (`/setmenubutton`), либо настроить **Web App** через `/newapp`.
3. Бот при команде `/start` должен присылать сообщение с inline-кнопкой типа `WebApp`, которая открывает игру:
   ```
   inline_keyboard: [[{ text: "🎮 Играть в Block Blast", web_app: { url: "https://your-domain.com/game" } }]]
   ```
4. Разместить игру на HTTPS-хостинге (обязательно HTTPS — Telegram Mini Apps не открывают http).
5. (Опционально) реализовать таблицу лидеров: бот получает результат через `sendData` или через свой backend API и хранит его в базе, показывая топ игроков командой `/top`.
