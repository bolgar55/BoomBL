# Эталон

## Внешний вид — цветовая палитра (дословно, ответ на вопрос про палитру)

Фон и сетка (нейтральная база):
- Фон приложения: тёмно-синий/графитовый `#1A1A2E` (тёмная тема) / светло-серый `#F0F0F5` (светлая)
- Клетки сетки (пустые): `#2C2C44` (тёмная тема) / `#E8E8F0` (светлая)
- Обводка клеток: полупрозрачная, чуть светлее/темнее фона

Цвета блоков (фигур) — яркие, контрастные друг другу, случайный цвет из набора при спавне фигуры:
- Красный `#FF4757`
- Оранжевый `#FFA502`
- Жёлтый `#FFD32A`
- Зелёный `#2ED573`
- Голубой `#1E90FF`
- Фиолетовый `#A55EEA`
- Розовый/малиновый `#FF6B9D`
- Бирюзовый `#00D2D3`

Плюс лёгкий градиент сверху вниз для объёма — «блоки выглядят глянцевыми, как в оригинальной игре».

Акценты:
- Взрыв линии: вспышка белого `#FFFFFF` + частицы в цвет блока
- Кнопки/UI: градиент фиолетово-синий `#6C5CE7` → `#A55EEA`
- Текст очков/комбо: золотой `#FFD700` с обводкой потемнее

## Принцип
- «Фон и сетка — приглушённые, почти монохромные, чтобы яркие блоки на них выстреливали. Если всё будет одинаково ярким, глаза устанут и потеряется контраст фигур.»
