# 05 — Языки и ежедневный челлендж

**Требования:** R14, R14.1, R14.2, R44, R44.1
**Blocked by:** 01, 03
**Зона:** `i18n/`, `game/challenges.js`
**Волна:** 3
**Status:** ready

## Что должно заработать

Весь видимый текст идёт через словарь на русском и английском, с переключателем языка; при первом запуске язык определяется автоматически (из Telegram, иначе из браузера, иначе русский). Ежедневный челлендж: цель определяется детерминированно по календарной дате устройства (один из 5 шаблонов), одинакова у всех игроков в этот день, прогресс виден на главном экране, обнуляется на следующий день, в первый день показывает 0 из цели, а не пусто.

## Из брифа, дословно

> «Ежедневные челленджи / уровни с целями» *(выбрано пользователем при брифинге)*
> «Язык интерфейса: (русский/английский/мультиязычность)» → «Оба (мультиязычность)»

## Разделы спецификации

Истории 18–20, 29–30, Решения §4 (челлендж), Границы (`i18n`, `challenges`), Швы — оба модуля тестируются напрямую.

## Критерии приёмки

- [ ] `i18n.t(key)` возвращает строку на текущем языке; `setLanguage('en'|'ru')` меняет язык мгновенно во всём интерфейсе
- [ ] `i18n.detectLanguage()` при первом запуске: язык Telegram-пользователя → иначе язык браузера → иначе `ru`
- [ ] `challenges.getTodayChallenge()` для одной и той же даты всегда возвращает один и тот же шаблон и цель (детерминированно по хэшу даты)
- [ ] Прогресс челленджа обновляется через `challenges.reportProgress(event)` по ходу партий и виден на главном экране
- [ ] В первый день без сыгранных партий прогресс показан как `0` из цели, без пустого экрана или ошибки
- [ ] При смене календарной даты устройства челлендж и прогресс сбрасываются автоматически
- [ ] Тесты на швах `i18n` и `challenges` покрывают: определение языка по умолчанию, переключение языка, детерминированность челленджа по дате, сброс прогресса на новый день
