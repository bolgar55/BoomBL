# 04 — Экран Game Over и звук

**Требования:** R20, R21, R27
**Blocked by:** 02, 03
**Зона:** `ui/gameover.js`, `ui/sound.js`, `assets/sounds/`
**Волна:** 3
**Status:** ready

## Что должно заработать

Когда `board.canFitAnywhere` возвращает `false`, игра показывает экран Game Over с итоговым счётом, кнопкой «Играть снова» (через `telegram-bridge.showMainButton`, видна только на этом экране) и кнопкой «Поделиться результатом» (через `telegram-bridge.shareResult`). Три звуковых эффекта — клик при постановке фигуры, взрыв при очистке линии, отдельный звук на game over — с одним переключателем «звук вкл/выкл», сохраняющим выбор между сессиями через `persistence`.

> «Экран Game Over с результатом, кнопкой «Играть снова» и кнопкой «Поделиться результатом»»
> «Telegram.WebApp.MainButton — например, кнопка «Играть снова» или «Поделиться»»

## Разделы спецификации

Истории 25–26, 36, Решения §7 («Поделиться» через `openTelegramLink`).

## Критерии приёмки

- [ ] Экран Game Over появляется ровно когда `canFitAnywhere` возвращает `false`, показывает итоговый счёт и (если побит) новый high score
- [ ] «Играть снова» реализована через `MainButton`, видна только на экране Game Over, скрыта во время игры
- [ ] «Поделиться результатом» открывает `openTelegramLink` со счётом в тексте
- [ ] Три звука — клик, взрыв линии, game over — присутствуют и звучат в соответствующие моменты
- [ ] Один переключатель отключает все три звука сразу, выбор сохраняется через `persistence` между сессиями
