# 01 — Ядро игровой логики: поле, фигуры, очки

**Требования:** R01, R03, R04, R06, R07, R08, R09, R10, R10.1, R11, R23
**Blocked by:** —
**Зона:** `game/board.js`, `game/shapes.js`, `game/score.js`, структура проекта (папки, `package.json` при необходимости)
**Волна:** 1
**Status:** ready

## Что должно заработать

Три чистых модуля без DOM и без Telegram, полностью описывающие правила Block Blast: поле 8×8, каталог фигур из ~24 форм (1–5 клеток, без поворотов), проверка «помещается ли фигура», фиксация хода с очисткой заполненных строк/столбцов, подсчёт очков по формуле, определение game over. Ничего не рисуется — это фундамент, на который дальше садится рендеринг (тикет 02).

## Из брифа, дословно

> «Игровое поле — сетка 8×8 клеток»
> «Внизу экрана показываются 3 случайные фигуры (составленные из 1–5 квадратов, формы как в Tetris/пентамино)»
> «Фигуру можно поставить только если все её клетки помещаются на свободные клетки сетки»
> «Когда полностью заполняется строка или столбец — она очищается (взрывается), клетки в ней зануляются»
> «Очистка нескольких линий одновременно даёт бонусные очки (комбо)»
> «Когда все 3 фигуры размещены — выдаются 3 новые случайные фигуры»
> «Игра заканчивается, когда ни одну из трёх текущих фигур невозможно разместить на поле (game over)»
> «Ведётся счёт очков: +очки за размещение блоков, +больше очков за очистку линий, множитель за комбо»

## Разделы спецификации

Истории 1–14, Решения §1 (каталог фигур), §2 (формула очков), §3 (game over), §10 (стек — Canvas 2D, без фреймворка), Границы (`board`, `shapes`, `score`).

## Критерии приёмки

- [ ] `board.canPlace(shape, row, col)` верно отклоняет позиции за границей поля и позиции с занятой клеткой
- [ ] `board.place(...)` фиксирует фигуру и возвращает список полностью заполненных строк/столбцов на очистку
- [ ] Одновременная очистка нескольких линий одним ходом обнаруживается как один результат хода, а не по одной линии
- [ ] `shapes.generateShapeSet()` всегда возвращает ровно 3 фигуры из каталога 1–5 клеток; ни одна форма не содержит операции поворота
- [ ] `score.addMove({cellsPlaced, linesCleared})` начисляет очки по формуле §2 (постановка — по клеткам, линии — `10×N²`, серийный множитель `(1+0.1×streak)`, ход без очистки сбрасывает серию)
- [ ] `board.canFitAnywhere(shapes)` верно определяет game over: `false`, когда ни одна из 3 фигур не помещается ни в одну из 64 позиций
- [ ] Тесты на швах `board`, `shapes`, `score` покрывают: успешную постановку, отказ при выходе за границу, отказ при занятой клетке, очистку одной линии, очистку нескольких линий одним ходом, game over, продолжение партии, когда есть хотя бы одна валидная позиция
