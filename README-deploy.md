# Деплой Block Blast как Telegram Mini App

Пошаговая инструкция: от кода в этой папке до рабочей игры внутри Telegram.
Хостинг — Vercel (бесплатный план, HTTPS из коробки, статика + серверлесс-
функции `/api/*` в одном проекте — spec §Решения 11).

Токен бота у вас уже есть (получен у @BotFather) — он нигде не пишется в код,
только в переменные окружения Vercel (шаг 3).

## 0. Что понадобится

- Аккаунт на [vercel.com](https://vercel.com) (можно войти через GitHub).
- Установленный `npm` (для команды `vercel`).
- Токен вашего бота от @BotFather (`TELEGRAM_BOT_TOKEN`).

## 1. Деплой на Vercel

Из корня проекта (там же, где `index.html` и `package.json`):

```bash
npx vercel --prod
```

Первый запуск спросит: привязать к существующему проекту Vercel или создать
новый — выберите «создать новый», примите путь проекта по умолчанию (текущая
папка). Команда сама увидит `index.html`/статические файлы и папку `api/` —
никакой ручной правки конфигурации не нужно (`vercel.json` уже настроен).

После завершения деплоя Vercel выведет адрес вида:

```
https://ваш-проект.vercel.app
```

Это и есть ваш **GAME_URL** — сохраните его, он понадобится дальше.

## 2. Переменные окружения в Vercel

В панели Vercel откройте ваш проект → **Settings → Environment Variables** и
добавьте три переменные (те же три строки, что и в `.env.example`, но с
реальными значениями):

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен вашего бота от @BotFather |
| `GAME_URL` | адрес, который выдал Vercel на шаге 1 (`https://ваш-проект.vercel.app`) |
| `STARS_AMOUNTS` | номиналы доната через запятую, например `25,50,100` |

После добавления переменных передеплойте проект, чтобы серверлесс-функции
подхватили новые значения:

```bash
npx vercel --prod
```

## 3. Настройка бота в BotFather

Откройте чат с [@BotFather](https://t.me/BotFather) и выберите один из двух
вариантов (оба закрывают R34/R35 — работает любой):

**Вариант А — Menu Button (быстрее):**

1. `/setmenubutton`
2. выберите вашего бота
3. в ответ на запрос URL пришлите ваш `GAME_URL` (с шага 1)
4. пришлите текст кнопки, например «Играть»

**Вариант Б — полноценный Web App через `/newapp`:**

1. `/newapp`
2. выберите вашего бота
3. заполните название, описание, картинку по запросу BotFather
4. в качестве URL Web App укажите ваш `GAME_URL`

Оба варианта открывают игру внутри Telegram как Mini App, разворачивающийся
на весь экран (R02/R24/R25 закрыты кодом — `telegram-web-app.js` и
`telegram-bridge.init()` вызывают `ready()`/`expand()` при старте).

## 4. Вебхук бота

Бот отвечает на `/start` inline-кнопкой и на успешные платежи Stars — эта
логика уже лежит в `bot/bot-logic.js` и вызывается из
`api/telegram-webhook.js`. Осталось сообщить Telegram, куда слать апдейты —
на адрес вашей же серверлесс-функции:

```bash
curl "https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook?url=https://ваш-проект.vercel.app/api/telegram-webhook"
```

Замените `<ВАШ_ТОКЕН>` на реальный токен и `https://ваш-проект.vercel.app` —
на ваш `GAME_URL`. Проверить, что вебхук встал, можно так:

```bash
curl "https://api.telegram.org/bot<ВАШ_ТОКЕН>/getWebhookInfo"
```

В ответе поле `url` должно совпадать с адресом выше, а `last_error_message` —
быть пустым.

## 5. Проверка

1. Откройте бота в Telegram, нажмите `/start` (или кнопку меню) — должна
   открыться игра на весь экран.
2. Сыграйте партию до Game Over — экран результата должен показать счёт и
   кнопки «Играть снова»/«Поделиться».
3. Переключите тему Telegram (Settings → Chat settings → Theme) прямо во
   время игры — интерфейс должен перекраситься без перезагрузки страницы.
4. Нажмите кнопку доната — должно открыться нативное окно оплаты Stars.
5. Переключите язык кнопкой RU/EN в шапке — тексты должны мгновенно смениться.

Если что-то не работает — сначала проверьте `getWebhookInfo` (шаг 4) и то,
что все три переменные окружения заданы в Vercel (шаг 2), затем передеплойте.

## Если используешь GitHub Pages

GitHub Pages отдаёт только статику — `index.html`, `app.js`, `style.css`,
папки `game/`, `ui/`, `i18n/`, `telegram/`, `assets/` там открываются и
работают нормально: сама игра (поле, фигуры, счёт, тема, звук, i18n,
локальный high score через `localStorage`) полностью играбельна.

Но серверлесс-функции из папки `api/` (`/api/config`, `/api/create-invoice`,
`/api/telegram-webhook`) на GitHub Pages **не выполняются** — там нет среды
выполнения кода, только раздача файлов. Из-за этого на GitHub Pages:

- кнопка доната не появится (`/api/config` недоступен → `STARS_AMOUNTS`
  не приходит → кнопка скрывается — это ожидаемо, не баг);
- бот не сможет принимать вебхуки Telegram (`/api/telegram-webhook`
  недоступен) — команда `/start` и обработка платежей Stars работать не будут.

Оба хостинга можно использовать одновременно: GitHub Pages — под саму игру
(`GAME_URL` в BotFather указывает на адрес Pages), а Vercel — только под
`api/*`. Тогда:

1. На GitHub Pages лежит и открывается сама игра — это ваш `GAME_URL` для
   BotFather (шаг 3 выше).
2. Отдельно задеплойте этот же проект на Vercel (шаг 1 выше) — оттуда
   понадобится только адрес `/api/*`.
3. В `index.html`/`app.js`, где идут запросы к `/api/create-invoice` и
   `/api/config` (см. `config.js`, `ui/donate.js`), эти пути должны вести на
   Vercel-адрес, а не на относительный `/api/...` (который на Pages ни на что
   не указывает) — например, через переменную `GAME_URL`-соседа
   `API_BASE_URL` в `vercel.json`/окружении, или проще: держите игру целиком
   на Vercel (раздел выше) — тогда статика и `/api/*` живут на одном домене
   и никаких дополнительных путей не нужно.
4. Вебхук бота (шаг 4 выше) в любом случае настраивается на Vercel-адрес
   (`https://ваш-vercel-проект.vercel.app/api/telegram-webhook`), а не на
   GitHub Pages — Pages вебхуки принимать не может.

Если донат и бот пока не нужны для теста — GitHub Pages для одной игры
вполне достаточно, ничего дополнительно настраивать не нужно.

## Локальная разработка (без Telegram)

```bash
npx vercel dev
```

Игра открывается в обычном браузере (`telegram-bridge` работает в безопасном
режиме без Telegram — R46i), но `/api/*`-функции при этом тоже работают
локально, включая `/api/config` (GAME_URL/STARS_AMOUNTS из вашего `.env`).

Без бэкенда вообще (`python3 -m http.server`) игра тоже открывается и
играбельна — кнопка доната в этом случае скрыта (нет `/api/config`), а
`GAME_URL` берётся из встроенного нефункционального плейсхолдера.
